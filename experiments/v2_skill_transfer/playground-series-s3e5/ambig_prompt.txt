# Tabular Playground Series S3E5 — Modeling Task

## Context

Synthetic tabular dataset generated from a deep learning model trained on the Wine Quality dataset. Feature distributions are close to, but not exactly the same as, the original. Each row corresponds to one wine sample.

## Files (in `data/`)

- `train.csv` — labeled records (1,645 rows).
- `test.csv` — held-out records (413 rows). Same schema as train except the target prediction column is missing — you must predict it.
- `sample_submission.csv` — an example submission file format.

## Columns

Examples of columns include: `Id`, `fixed acidity`, `volatile acidity`, `citric acid`, `residual sugar`, `chlorides`, `free sulfur dioxide`, `total sulfur dioxide`, `density`, `pH`, `sulphates`, `alcohol`, `quality`. (Inspect `train.csv` for the full schema.)

## Evaluation

Predictions are evaluated by the **Quadratic Weighted Kappa (QWK)** metric on the test set, computed against integer-valued predictions.

The QWK metric weights misclassifications by the squared distance between predicted and actual ordinal values, divided by `(N-1)^2` where `N` is the number of possible values. It is calculated as

\[ \kappa = 1 - \frac{\sum_{i,j} w_{i,j} O_{i,j}}{\sum_{i,j} w_{i,j} E_{i,j}} \]

where `O` is the confusion matrix, `E` is the expected matrix under independence, and `w` is the squared-distance weight matrix. Higher is better.

## Submission format

CSV with header:

```
Id,<target>
2056,<value>
2057,<value>
...
```

Replace `<target>` with the column you are predicting; `<value>` is your prediction for that `Id`.
